Banners

Cada banner tem um link fixo. Ao trocar a imagem no repositório, mantendo o mesmo nome de arquivo, o link continua o mesmo.

Para trocar um banner: envie o novo arquivo para a pasta img/ do repositório com exatamente o mesmo nome, terminando em .jpg. Se a imagem for GIF, PNG ou WebP, renomeie o arquivo para .jpg antes de enviar (com as extensões de arquivo visíveis no computador). O site pode levar alguns minutos para mostrar a versão nova.
