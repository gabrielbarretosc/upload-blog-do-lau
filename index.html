Banners

Cada banner tem um link fixo. Ao enviar uma nova imagem, o link continua o mesmo.

Acesso para enviar imagens Sem acesso configurado

Cole aqui o token de acesso que você recebeu. Ele fica salvo só neste navegador, então você informa uma vez.

Para trocar um banner: clique em Trocar imagem, escolha o arquivo (JPG, PNG, GIF ou WebP) e clique em Enviar. O arquivo é salvo sempre no nome fixo do banner (.jpg), sem precisar renomear, e GIFs continuam animados. O site pode levar alguns minutos para mostrar a versão nova.
